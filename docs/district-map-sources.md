# 자치구 인구 지도 근거

내부 기록 · 확인일 2026-10-05. 날짜·원본 경로·고정 리비전은 공개 UI로 출력하지 않는다.

## 선택한 지표

분석 입력 자료의 자치구별 인구, 단위 명. 범죄 건수·잔차·예측값을 색으로 표시하지 않는다. 원본의 범죄 타깃 중복 합산 결함과 독립적으로 수집한 입력변수이며, 별도 인구 원본과 25개 값을 직접 대조했다. 면적당 인구밀도로 소개하지 않고, 현재 인구라는 표현도 사용하지 않는다.

공개 캡션: `서울 25개 자치구 · 분석 입력 자료의 인구(명). 진한 색일수록 큰 인구 규모. 면적당 밀도가 아닌 자치구별 인구 합계.`

- [인구 전처리 코드](https://github.com/Ryu-Jemu/crime-analysis/blob/103f8d7972dd81670bcc5fe7d08257f416b5bb71/Version02/preprocessing.py#L21): 22–27행에서 인구 CSV의 헤더 처리, 자치구 행 선택, 소계 제외, 쉼표 제거와 숫자 변환, 자치구·인구수 열 선택. 범죄 자료는 별도 집계 경로.

## 색상 구간

독자가 읽기 쉬운 인구 기준을 직접 지정한 5구간이다. 분위수·순위·통계적 위험 등급이 아니다. 하한은 포함하고 상한은 포함하지 않는다. 무지개·발산색 대신 밝은 파랑에서 진한 파랑으로 이어지는 단일 계열 사용.

## 구현과 접근성

- 데이터: `src/data/district-metrics.ts`의 `districtPopulation`, `populationByDistrict`, `populationBands`, `populationBandFor`.
- 도식: `src/components/viz/DistrictMap.astro`; 독립 `StudyFigure`로 배치 가능. 선택 지표 전환이나 외부 요청 없음.
- SVG는 반응형 크기. 작은 화면에서 이름이 겹치지 않도록 모든 자치구명을 SVG 안에 상시 인쇄하지 않음.
- 각 경계에 자치구명·정확한 인구의 `title`과 접근성 이름 제공. 선택 이름·인구는 지도 아래 별도 텍스트로 표시.
- 클릭·터치·포커스·포인터로 선택. 키보드 방향키는 가나다순 전후 자치구 이동, Home/End는 처음/마지막 자치구. Enter/Space로 선택. JavaScript 실행 시 지도에 탭 진입점 하나를 유지.
- 색 없이도 확인 가능한 전체 25개 수치 표와 명확한 범례 제공. 표는 접힌 기본 상태에서 기본 HTML `details`로 열기 가능.
- JavaScript 없이도 모든 경계의 제목·접근성 이름과 수치 표 사용 가능. 모션 없음.
- 정확 수치는 `Intl.NumberFormat('ko-KR')`로 표시. 공개 날짜·검증 메타데이터 없음.

## 확인한 범위

원본 파일·원본 저장소 변경 없음. 원본 분석 코드·API 수집 실행 없음. 읽기 전용 HTTP 조회와 로컬 대조만 수행.

1. 인구 원본 ↔ 결합 CSV: 자치구명·인구 25개 전부 일치.
2. 새 TypeScript 데이터 ↔ 결합 CSV: 25개 전부 일치, 합계가 인구 원본 합계와 일치.
3. 경계 ↔ 데이터: 이름 집합 25개 일치, 누락·중복 없음.
4. 기존 경계 ↔ 공통 SVG: 경계 경로 25개 정확히 일치.
5. 모든 색상 하한·상한 경계 검사 통과; 구간별 자치구 수 합계 25.
6. Astro 컴파일러의 컴포넌트 구문 진단 없음. 실제 페이지 배치·브라우저 상호작용은 상위 작업의 화면 검수에 포함.
