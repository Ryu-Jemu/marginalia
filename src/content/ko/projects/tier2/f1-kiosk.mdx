1080×1920 세로 화면 6개를 구현했습니다. 공통 헤더에는 시계와 다음 레이스까지의 카운트다운을 표시합니다.

자동 재생과 수동 조작을 하나의 상태 머신으로 관리합니다. 터치 입력이 들어오면 자동 복귀를 일시 정지하고, 마지막 입력 후 50초가 지나면 첫 화면으로 돌아갑니다.
