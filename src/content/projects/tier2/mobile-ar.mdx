A hand landmark model gives the index fingertip, projection puts it in world
space, and a pinch between finger and thumb toggles drawing. The input source
sits behind an interface so the simulator, the webcam and a real device are all
the same thing to the code above it.

It has never run on a phone. I do not own an ARCore device, so it is verified
against synthetic input and a laptop camera only.
