### 값 및 통계 조건

| 정책 | 평균 누적 순보상 | 학습 seed 평균 간 표준편차 |
|---|---:|---:|
| PPO | 7333.992583213748 | 243.07034624090343 |
| SAC | 7369.822912624568 | 542.257538629781 |
| TD3 | 6862.051039033632 | 56.036892017045126 |
| Max-Price | 7182.888937446574 | 적용하지 않음 |

- 학술대회 원 실험의 `m=1`, URLLC/eMBB, 외생 QoS 환경.
- 에피소드 누적 순보상은 매 스텝 `(청구 수익 − QoS 페널티) × 10⁻⁵`를 합한 값. 실제 매출 금액이 아님.
- 학습 정책은 seed 42·123·456 각각의 평가 에피소드 20회 평균을 사용하고, 그 세 평균의 평균·모집단 표준편차를 표시.
- 오차선은 `sqrt(sum((seed_mean − mean)²) / 3)`. 신뢰구간·표준오차·전체 에피소드 간 표준편차가 아님.
- Max-Price는 학습 없는 고정 정책의 평가 20회 평균. 원본의 `std_reward`는 평가 에피소드 간 산포이므로 학습 seed 간 산포와 같은 오차선으로 섞지 않음.
- 평균·SD를 저장된 세 seed 값으로 재계산해 일치 확인. 그래프는 정수 반올림, 펼친 데이터 표는 소수 둘째 자리 표시.
- 이후 학술지 확장 실험의 학습 7seed·평가 1000–1019 분리 프로토콜과 혼용하지 않음. 원 실험 코드는 각 학습 seed를 평가의 시작 seed로 전달함.
- Myopic-PPO는 `src/scripts/make_paper_figure.py:198`에 오래된 `multi_seed_results.json` 항목을 피하고 `myopic_sweep_results.json`을 사용하라는 교정이 있으므로 이번 도표에서 제외.
- 이 그림은 낮은 민감도 조건의 비교이며 PPO의 전 조건 우위·실제 통신망 수익 개선·운영 효과를 뜻하지 않음.

### 계층과 학습 대상

- GPT-2 본체의 가중치는 `requires_grad=False`로 동결: cell 1:142.
- 결합 모듈은 패치 투영·패치 어텐션·어휘 프로토타입 투영·재프로그래밍 어텐션·GPT-2 입력 투영·출력 투영.
- 학습 가능한 결합 모듈 합계 339,338개는 **전체 GPT-2 파라미터 수가 아님**. optimizer는 `requires_grad=True`인 파라미터만 전달받음: cell 1:252.
- 실제 텍스트 prefix이며 LoRA·학습 가능한 soft-prefix 구현으로 표시하지 않음.
- 코드 클래스명이 CrossVariableAttention이어도 실제 호출은 `patches, patches`. 서로 분리된 변수 스트림의 정교한 교차 정렬이라고 확대하지 않음.
- 프로토타입은 어휘 임베딩의 앞부분을 선택. 의미적으로 최적의 단어를 학습 선택한 구조로 표시하지 않음.
