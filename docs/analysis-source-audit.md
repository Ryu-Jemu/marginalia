### 전처리와 모델의 설명 범위

고정 소스 `Version02/preprocessing.py`:

- 8–11행: CCTV의 자치구 문자열 정리와 자치구별 개수 집계.
- 22–27행: 인구표의 자치구 행 선택, 소계 제거, 쉼표 제거와 숫자 변환.
- 30–33행: 소득 CSV의 인코딩 처리, 지역 접두어 제거와 숫자 변환.
- 36–41행: 유흥주점 주소에서 구 추출, `영업/정상` 필터와 개수 집계.
- 44–45행: 자치구 기준 outer join.
- 48–53행: 서울 25개 자치구로 제한.
- 55–56행: 결측값을 0으로 채움. 실제 구현을 설명하는 항목이며 모든 결측값 처리에 적합하다는 평가가 아님.

`Version02/value_heatmap.py` 18·22·26행에 변수 선택, `df.corr()`, 소수 둘째 자리 표시가 있다. 이전 원장 31–35행과 발표 PDF 34쪽은 공공데이터 결합, 가로등 추정, 상관·VIF·회귀 비교의 분석 흐름을 뒷받침한다.

`Version02/Lasso&Ridge.py` 19–20행은 전체 입력에 StandardScaler를 적용한다. 23–29행의 LassoCV와 37–43행의 RidgeCV는 교차검증으로 정규화 강도를 선택하지만, 표시한 R²는 학습에 사용한 전체 입력을 다시 예측해 계산한다. 이 점수를 독립 평가셋의 예측 성능이나 일반화 성능으로 소개하지 않는다. 공개 시각화는 OLS의 기준 회귀, Lasso의 계수 축소·변수 선택, Ridge의 계수 축소라는 목적 비교로 한정한다.

- 최신 개인 저장소 원장 54행: 범죄 소계와 하위 범죄 항목을 함께 합산하여 25개 자치구 전체에서 타깃이 중복 합산됨. `Version02/preprocessing.py` 14–18행이 해당 집계 경로.

- 4인 팀 과제의 번호별 역할표만으로 사용자 개인 역할을 새로 단정하지 않음. 최신 원장 48–54행의 팀 범위와 구현 자료를 함께 적용.

## 영화관 분석: 권역 상관 재계산과 입력 정합성 제한

원본 `Number_Share_Analysis.py` 8–22행의 저장 배열을 기준으로 계산했다. 워크북 `Number_of_theater.xlsx`의 `Sheet2!A23:D33`과 영화관 수 배열이 일치한다. 권역 순서는 서울, 경기, 인천, 강원, 충청/대전/세종, 경상/대구/부산/울산, 광주/전라, 제주다.

| 입력 | 8권역의 저장 값 |
| --- | --- |
| 메가박스 | 20, 31, 6, 17, 27, 9, 4, 3 |
| 롯데시네마 | 23, 41, 4, 12, 42, 11, 6, 2 |
| CGV | 31, 59, 12, 23, 44, 23, 5, 1 |
| 지역 점유율(%, 2020 열) | 23.1, 27.1, 5.3, 2.3, 10.2, 22.6, 8.4, 1.2 |

다음 값은 저장된 분석 입력을 재계산한 결과다. 실제 권역별 집계의 타당성을 검증했다는 뜻은 아니다.

| 체인 | Pearson r | 양측 p | 표본 |
| --- | ---: | ---: | --- |
| CGV | 0.6839913118 | 0.0613764039 | 동일한 8권역 |
| 롯데시네마 | 0.5685788302 | 0.1413951729 | 동일한 8권역 |
| 메가박스 | 0.5496820760 | 0.1581357414 | 동일한 8권역 |

표시 반올림 r = 0.684 / 0.569 / 0.550, p = 0.0614 / 0.1414 / 0.1581은 공유 `공통_디자인자산_웹도식_영화관_권역상관계수_웹추출본_20260922.svg` 및 보존본 `CinemaCorrelation.astro`와 일치한다. 모든 p가 0.05보다 크므로 유의한 상관이나 인과관계, 무상관을 입증하는 문구를 사용하지 않는다. 세 체인의 종속 입력은 동일한 전체 지역 점유율이며 각 체인 자체의 지역 점유율이 아니다.

재계산은 `statistics.correlation`과 n=8인 Pearson 영가설의 정확한 양측 분포를 사용했다. 절댓값 a=|r|에 대해 `p = 1 - 15/8 × (a - 2a³/3 + a⁵/5)`로 독립 계산했다. 원본 scipy 분석 코드나 네트워크 수집을 실행하지 않았다.

- `Sheet1!E1`은 `영화관명`, `H1`은 `스크린명`, `I1`은 `스크린별 좌석수`; 동일 영화관에 여러 스크린 행이 있음.

### 추가로 발견한 정합성 한계

`Sheet2!A28:D28`의 강원 체인 합계는 17+12+23=52다. 같은 시트 `A6:B6`의 강원 전체 영화상영관 수는 28이다. 이 두 표를 동일 시점·동일 기준으로 간주하면 양립하지 않는다.

`Sheet1`에서 광역단체·영화관명·스크린명이 모두 있는 행을 읽고 영화관명을 단순 중복 제거하면 강원 메가박스 4·롯데시네마 4·CGV 6으로 저장 분석 배열과 일치하지 않는다. 이는 명칭 정규화·특별관 병합·시점 통일을 완료한 새 통계가 아니며 원본 숫자를 교체할 근거로 사용하지 않는다. 서로 다른 시점·집계 기준인지, 지역 매핑 또는 수기 입력 오류인지는 현재 근거로 확정할 수 없다.

따라서 상관계수의 **계산 재현은 확인**, **권역 입력의 정합성은 미확정**으로 구분한다. 이번 개편에서는 권역 상관의 공개 차트와 데이터를 전면 제외하기로 확정했다. 이 문서의 수치는 내부 추적용이며 현재 시장의 검증된 관계나 성과로 설명하지 않는다.

### 소비지출 행 제외

`Consumtion_Share_Analysis.py` 6–14행의 2022 배열은 소비지출 `[2662,2181,2113,2024,2107,2106,2020,2227]`, 지역 점유율 `[25.3,25.6,5.1,2.5,10,21.8,8.4,1.2]`다. 43행의 단위는 1인당 민간소비지출액, 만 원이다. 재계산 r=0.5321137792, p=0.1746208466으로 기존 SVG의 0.532·0.1746과 일치한다.

기존 4항목 도식은 체인 3개의 2020 점유율과 소비지출의 2022 점유율을 혼합했다. 동일 조건의 4개 비교처럼 재사용하지 않는다. 현재 개편에서는 소비지출 행을 제외한다. 워크북의 권역별 소비지출에는 소수점 값이 있으나 코드 입력은 일부 반올림되어 있으므로 원본 코드의 결과와 워크북 직접 재계산 결과를 무조건 동일시하지 않는다.

확정 공개 구성은 범죄의 입력변수 히트맵·전처리 흐름·모델 목적 비교, 영화관의 원본 키워드 빈도·수집→명사 추출→불용어 제거→빈도 집계 흐름·기존 실제 입지 지도다. 실제 입지 지도는 기존 원본 앱의 캡처·지도 자료 범위를 유지하며 새 인과 해석을 붙이지 않는다. 분석 방법과 실제 산출물을 보여주되, 팀 분석을 개인 단독 성과로 바꾸거나 미확정 입력의 상관값을 성과로 강조하지 않는다.
