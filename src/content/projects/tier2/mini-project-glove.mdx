Rulebook PDFs are stored in MinIO, split along their document structure and
indexed in PostgreSQL with pgvector. Rule-number matches, dense retrieval and
Kiwi-based BM25 are combined with reciprocal rank fusion. Parent sections
restore the context around a retrieved clause before it reaches the model.

Retrieval distinguishes weak evidence from a failed embedding request. Context
selection applies a token budget and a relative relevance threshold, while
protecting the highest-ranked documents from that threshold. These checks
address different failures: unrelated context and relevant clauses removed
during fusion.

FastAPI serves the Streamlit interface over SSE. A structured answer schema and
a Python renderer separate the answer content from its presentation. Citation
checks compare rule references with retrieved material. The evaluation code
checks routing, expected clauses, refusal wording and schema fallbacks against
curated cases.
