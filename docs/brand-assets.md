# 기술 배지 자산

내부 출처 기록. 공개 화면에는 기술명과 마크만 표시.

- 로고 SVG: https://github.com/simple-icons/simple-icons/tree/16.0.0/icons
- 라이선스: `brand-icon-license.txt`, CC0. 제품명과 로고의 상표권은 해당 소유자에게 있음.
- `public/brands/`에 필요한 원본 SVG만 저장. 외부 CDN 실행 요청 없음.
- PostgreSQL 계열인 PostGIS·pgvector는 PostgreSQL 마크와 확장 이름을 함께 표시. 자체 PostGIS 로고로 소개하지 않음.
- 공식 마크를 포함하지 않은 도구는 약자 마크 사용. Codex의 >_ 기호도 자체 약식 표시.
- 색은 작은 글자의 명암 대비를 위해 배지별로 조정. 사용자 제공 예시의 기술명·색 구분 방식 참고.
- 배지는 비대화형 span. 실제 탐색은 강조 링크·버튼·펼침 요소로 구분.
