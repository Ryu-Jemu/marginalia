## Source data and team contributions

MAP turns weather, places, reviews and transport data into a saved itinerary. I took responsibility for **architecture, AI, backend, service integration, GCP/NCP and app submission**. Teammates handled design and initial frontend setup and contributed the initial authentication, cache, vision and several app features. The contribution table details my implementation and later improvements.<N id="map-ownership" />

**App status: submitted for store review and awaiting a decision**, confirmed on 2026-09-20. My release work includes signed builds, artifact checks, distribution and submission.<N id="map-store-review" />

## Input quality and stored data

**Provider failures and empty results require different handling.** I separated an unavailable provider from a successful empty search, checked KMA page totals before storage, and kept valid PM2.5 when PM10 was missing. Test data uses an explicit mode and a separate cache namespace. Hub retains usable results from other sources; Agent returns a classified failure when verified candidates are unavailable.<N id="map-provider-quality" />

**I normalized course sources, coordinates and route metadata.** The shared representation supports PostGIS upserts and radius queries. Forecast lookup maps a requested district to a subscribed grid in the same province. Redis L1 and scheduled PostgreSQL prefetch serve different source and freshness requirements.<N id="map-cache-tiers" />

## Asynchronous state and private results

The BFF accepts a job, Agent retrieves data through Hub, and a Redis Streams completion returns to the BFF for storage. I separated acceptance and terminal writes so a delayed acceptance could not reset a completed job.<N id="map-terminal-state" />

**A shared result must retain its original meaning.** A regression reproduced a waiting user receiving the producer’s personal edit. I changed the shared read to an immutable worker snapshot. Encryption also authenticates the producer and execution ID with the body—additional authenticated data, or AAD. Each user’s editable result follows a separate path. A persisted follower deadline allows a later lookup to finish an expired wait after Redis metadata is lost.

The **2026-09-09 focused run** passed 93 regressions with real service, consumer and store code, H2 and encryption. Redis primitives used memory doubles.<N id="map-test-count" />

## Recommendation and app contracts

- **Calculated routes** — The graph covers candidate preparation, selection, routing, timetables and completion.<N id="map-graph" /> Normal recommendation uses a model for selection and explanation. A supplied-place route verifies its source, skips both model calls and changes order only on an explicit optimization request.<N id="map-llm-budget" />
- **Account limits** — Authenticated re-search uses an account counter with KST-midnight expiry. Redis counter errors remain fail-open.<N id="map-rate-limit" />
- **App integration** — I connected persisted consent revisions and error codes to Flutter. Late consent responses are checked against the current account/revocation state; recommendation errors retain their retryability. Chat changes suppress repeated reads from the caller’s own read events.<N id="map-client-contract" />

## Export and deployment checks

**Export uses the same decryption contract as serving.** I corrected reads that could turn encrypted itineraries into empty labels, then separated export into a non-web process with approval and read-only connection checks. The saved synthetic-key/H2 run covers label equivalence and damaged envelopes. Capture/export remain off by default; there is no model-training result to report.<N id="map-training-boundary" />

**Deployment records carry their environment.** The GCP test deployment recorded on 2026-09-20 completed its release and smoke checks. NCP’s September User-image change has separate health and access-control evidence, including its interruption window.<N id="map-deployment" /> The source snapshot is dated 2026-09-20; the latest saved NCP runtime observation is 2026-09-19.
