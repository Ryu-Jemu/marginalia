A hand landmark model gives the index fingertip, projection puts it in world
space, and a pinch between finger and thumb toggles drawing. The input source
sits behind an interface so the simulator, the webcam and a real device are all
the same thing to the code above it.

Every milestone passed except the one that matters most: it has never run on a
phone. I do not own an ARCore device, so this is verified against synthetic
input and a laptop camera. It is paused there, and it is listed here in exactly
that state rather than described as if the last step happened.
