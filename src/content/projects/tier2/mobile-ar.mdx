A hand landmark model tracks the index fingertip, which is projected into 3D world space. A thumb–index pinch toggles drawing. A shared input interface lets simulated, webcam and device input connect to the same drawing code.

Validation used synthetic input and a laptop camera. Execution on an ARCore device remains unverified.
